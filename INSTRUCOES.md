# Missão Código Livre | SENAI

Página Web estática, feita em HTML, CSS e JavaScript, para publicar no GitHub Pages. Não exige banco de dados nem instalação.

## Atividade

Os grupos escolhem um dos quatro programas simples: conversão de reais para dólares, IMC, desconto ou temperatura. Podem programar em Python (Google Colab) ou Java (OneCompiler). Há pseudocódigo e dicas de sintaxe, mas as soluções completas nas duas linguagens são bloqueadas até a confirmação de conclusão.

Depois de registrar a linguagem preferida e o motivo, clicar em **Missão finalizada com sucesso** abre uma confirmação irreversível. Se confirmarem, os exemplos de referência em Python e Java aparecem juntos, com orientações para comparação.

**Importante:** o bloqueio usa `localStorage` no navegador, portanto é uma regra didática, não uma proteção contra alunos tecnicamente experientes. O site não coleta/envia respostas. O professor deve receber a demonstração do programa e a resposta do grupo pelo AVA ou em sala. A cotação R$ 5 por US$ 1 é fictícia, apenas para cálculo.

## Publicação no GitHub Pages

1. Crie um repositório público no GitHub.
2. Faça upload do `index.html` na raiz do repositório.
3. Acesse **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**, branch `main`, pasta `/(root)` e salve.
5. Aguarde o GitHub publicar o endereço informado na mesma página.

`index.html` é autossuficiente e pode ser aberto localmente para prévia.
