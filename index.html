👥 Como funciona a missão

  1. Formem grupos e escolham um dos quatro desafios.
  2. Escolham a linguagem: Python ou Java.
  3. Leiam o que o programa precisa fazer e consultem as dicas, se necessário.
  4. Criem e executem o código. Podem usar IA, mas precisam entender o resultado.
  5. Mostrem ao professor o programa funcionando e respondam qual linguagem o grupo mais gostou.
  6. Cliquem em Missão finalizada com sucesso. Após confirmarem, o site mostra os códigos completos em Python e Java, para comparar com o trabalho do grupo.

Sem avaliação e sem ranking. O que importa é criar algo funcional e conseguir explicar a própria escolha.

    💡 Dicas de código
    Primeiro, tentem por conta própria. Abram só a dica que estiver faltando.
    Dica 1. Como ler informações do usuário?
    Python: valor = float(input("Digite um número: "))
    Java: Scanner entrada = new Scanner(System.in); e depois double valor = entrada.nextDouble();. Adicionem import java.util.Scanner; no início.
    Dica 2. Como mostrar o resultado?
    Python: print("Resultado:", resultado)
    Java: System.out.println("Resultado: " + resultado);
    Dica 3. Como criar uma condição?
    Python: if valor > 0: e, na linha seguinte, uma instrução recuada.
    Java: if (valor > 0) { ... }. A condição vai entre parênteses e o bloco usa chaves.
    Dica 4. Como pensar no cálculo do desafio escolhido?
    Dica 5. Posso usar IA?
    Sim. Peçam explicações e ajuda para corrigir erros. Exemplo de pedido:
